## Phase 4 Prompt Rules (Webflow AI)

Ziel: Der Prompt erzeugt **strukturierte Drafts** (Layout/Sections/Constraints) — **nicht** die finalen Inhalte.

**Prompt enthält (MUSS):**
- Pages/i18n Setup (FastShip): 2 Pages (/en Default, /de Secondary) + optional Redirect / → /en
- Section-Stack + Reihenfolge (Hero/Offer/Hours/Events/Gallery/Location/FAQ/Form/Footer)
- CTA-Policy (Primary + Secondary)
- Style Constraints (Mood/Colors/Type)
- Form: Felder + Required/Checkbox + grobe Success Message + Notification Email (MVP)

**Prompt enthält NICHT (SOLL NICHT):**
- Finalen Fließtext für alle Sections (kommt aus Phase 5 Content Pack)
- “Perfektes” i18n-System (Localization/Complex routing) – nur FastShip Pages
- Tool-Integrationen außerhalb Webflow (keine Add-ons in Phase 4)

**Warum:** Webflow AI + Zeichenlimit + Varianz → Final-Content wird deterministisch in Phase 5/6 nachgezogen.

## GO Gate (Hard Rule)
